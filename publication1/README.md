# publication1 — Paper 1 LaTeX source

Benchmarking trajectory-tracking controllers for the Crazyflie 2.1 brushless under
disturbances and realistic sensing. Results are complete (2026-07-23); this directory
holds the manuscript.

## Layout
```
main.tex          SPIE document (\documentclass[nocompress]{spie}), includes the sections
abstract.tex      abstract + keywords            [written]
introduction.tex  challenge / related work / approach / contributions   [stub]
methodology.tex   platform, metrics, pool, training, conditions, stats  [stub]
results.tex       eight result subsections                             [stub]
conclusion.tex    closing + limitations + future work                   [stub]
refs.bib          bibliography
figures/          generated figures (PDF, vector)
OUTLINE.md        section-by-section plan, claim map, figure/table plan
```

`spie.cls` and `spiebib.bst` are not vendored — download the SPIE Proceedings author
kit and place both next to `main.tex`.

## Build
```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Conventions
- Learned policies use descriptive names in the text (DATT-L1, DATT-Noisy, DATT-Asym,
  DATT-Stack); the mapping to repository tags v3/v4/v5/v6a is given once in the
  methodology section.
- Every quoted number must be traceable to `reports/*.md` or
  `papers/paper1-benchmark/README.md`; cells with seed statistics are quoted as
  mean ± std with the seed count stated.
- Figures are generated by scripts against the immutable `results/` run directories
  (see the figure table in `OUTLINE.md` for the source runs).
