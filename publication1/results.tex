\subsection{Lessons learnt}
\label{sec:results:lessons}
% TODO. Table 4. Seven lessons, each as claim / mechanism / evidence:
%  L1 Disturbance estimation is the price of entry.
%  L2 One observer bandwidth knob cannot do two jobs (and innovation scheduling fails
%     because the statistic cannot separate an external disturbance from the observer's
%     own attitude-lag residual).
%  L3 Mean-only tables mislead: 0.228 +- 0.178 [0.091-0.480] and 0.323 +- 0.106 are
%     failures on unlucky bias draws; the learned policy's edge is a variance collapse
%     (+- 0.007), not a mean shift.
%  L4 Audit transients before blaming noise: a launch excursion outside the warm-up
%     window, steady-state error a quarter of the full-window figure, fixed by a 1.5 s
%     observer soft-start -- and the residual is generic to the predictive family.
%  L5 Single-seed policy conclusions invert: a clean-state regression we reported
%     reversed at three training seeds (best draw vs. worst draw).
%  L6 Robustness is bought with agility, at a measurable exchange rate; a memoryless
%     policy averages over the randomization range instead of calibrating, and frame
%     stacking did not fix it at this budget.
%  L7 Mechanisms compose when they address disjoint error sources -- an ESO cancelling
%     external force over a learned rate loop that makes command realization
%     airframe-independent yields payload invisibility; neither layer does it alone.
